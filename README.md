# [AlesioKanani.github.io](https://alesiokanani.github.io)

**DRIFT**: press start and your cursor becomes a starship. Steer through deep space, blast asteroids, collect energy orbs and follow the signal through wormholes into new sectors.

- Move: steer (push toward the edge of the screen to fly faster)
- Click / hold: fire
- Space: warp
- M: sound on/off · Esc: land

Everything is one self-contained `index.html` (canvas + Web Audio, no build step).
The previous site lives at [`puzzle.html`](https://alesiokanani.github.io/puzzle.html).
